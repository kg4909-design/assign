# 솔로몬 — 학년·업무 배정 시스템

학교 인사자문위원회 규정에 따라 순위를 정하고, 선생님들이 차례대로 **학년과 업무를 선택**하는 웹앱입니다.

## 🔗 접속 주소

**https://kg4909-design.github.io/assign/**

- 교사·교감: 위 주소를 열면 항상 **학교 코드 입력 화면**이 먼저 나옵니다. 학교 코드를 입력하고 **입장하기**를 누르세요. (학교에서 받은 입장 링크로 열면 코드가 미리 채워져 있어 **입장하기**만 누르면 됩니다.)
- 제작자: 위 주소 첫 화면의 **🔧 제작자 콘솔**에서 학교를 만들고 인사담당자 비밀번호를 발급합니다.

## 💬 의견·문의 / 🔑 비밀번호 분실

- **의견·문의**: 첫 화면(또는 학교 화면 위쪽)의 **💬 의견·문의**로 오류 신고, 내용 수정 요청, 개선·기능 요청을 남길 수 있습니다. 답장은 글을 보낸 **같은 기기·브라우저**의 [내 의견] 탭에서 볼 수 있습니다. 교사 이름·점수·비밀번호는 쓰지 마세요.
- **비밀번호 분실**: 인사담당자(교감)가 비밀번호를 잊으면 첫 화면의 **🔑 비밀번호 분실 신청**에 지역·학교 이름·**공직자통합메일 주소**를 남깁니다. 제작자가 그 메일이 실제 해당 학교 교감의 것인지 확인한 뒤, 새 비밀번호를 그 메일로 보냅니다. 신청 정보는 처리 후 삭제됩니다.

## 사용 순서

1. **제작자**가 제작자 콘솔에서 학교(지역·학교 이름·규정 템플릿)를 만듭니다. → 학교 코드, 입장 링크, 인사담당자 비밀번호가 한 번만 표시됩니다.
2. **인사담당자(교감)**에게 입장 링크와 비밀번호를 전달합니다.
3. **교감**은 입장 링크로 들어가 오른쪽 위 **관리자**를 누르고 비밀번호를 입력합니다. 관리자 화면의 ① 학교 준비 탭에서 규정·학년 정원·업무 목록(업무분장표로 자동 생성 가능)을 설정합니다.
4. **교감**이 입장 링크만 교사들에게 나눠 줍니다. (비밀번호는 교사에게 알리지 않습니다.)
5. 교사가 0단계에서 점수·경력을 입력하면 교감이 확인하고, 1단계(학년) → 2단계(업무) 순서로 진행합니다.

## 📜 규정 PDF 자동 해석 · 매년 재사용

- 관리자 화면 ① 학교 준비 → **규정 PDF 올리기**: 인사위원회 규정 PDF를 올리면 점수표·동점 기준·우대 대상·업무 순서·부장 목록을 **문장 패턴으로 찾아 제안**하고(원문 조항 함께 표시), 자동으로 해결되지 않는 **확인할 점**(재량 배정, 나이 기준, 추첨, 연속 연한, 조 번호 누락 등)을 알려 줍니다. 서버·AI를 쓰지 않고 이 기기 안에서만 처리합니다.
- 회의 후 **개정안·회의 결과 PDF**(또는 글)를 다시 올리면 현재 설정과 **달라진 점만** 보여 주고, 체크한 것만 반영합니다.
- 자동 해석은 틀릴 수 있으므로 항상 [미리보기]로 순위 변화를 확인한 뒤 적용하세요. 최종 판단은 인사위원회·교감입니다.
- **학교 템플릿**: 규정·정원·업무·우대 항목은 학교에 계속 저장되어 매년 그대로 씁니다. JSON으로 저장·공유할 수 있고, **새 학년도 시작**으로 명단·진행 상태만 비울 수 있습니다.

## 구조

- 화면: `index.html` 한 파일 (GitHub Pages로 배포)
- 데이터: Firebase Realtime Database (학교별로 분리 저장)
- 로그인: Firebase Authentication (교사는 익명, 교감·제작자는 비밀번호)
- 보안: Firebase 규칙이 실제 잠금 역할을 합니다. 규칙이 공개 상태이면 누구나 데이터를 바꿀 수 있으니 반드시 규칙을 적용하세요.

## 주의

- 이름·점수·경력 등 개인정보가 저장됩니다. 학교 코드와 입장 링크는 해당 학교 교사에게만 공유하세요.
- 인사담당자·제작자 비밀번호는 화면에 한 번만 표시됩니다. 따로 안전하게 보관하세요.
